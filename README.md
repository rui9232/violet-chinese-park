# Violet的中文樂園

國小 1～6 年級的中文遊戲網站。小朋友選年級闖關，老師／家長可以自己出題，產生四碼房間碼給孩子玩。

**直接玩（不用安裝）：**  
https://rui9232.github.io/violet-chinese-park/

這個倉庫仍保留完整原始碼。線上版是另外自動打包發布的，不會蓋掉這裡的檔案。

## 可以做什麼

- 六座年級島：注音、識字、詞語、句子、成語、閱讀
- 動腦筋：猜猜我是誰、找好朋友、記憶魔法卡、小耳朵挑戰、補洞洞、排字小火車、誰是小壞蛋
- 學部首：部首猜猜樂、部首一家人、字找部首、部首獵人
- 動一動：打地鼠學中文、小墨衝刺、氣球爆破
- 老師魔法工坊：一題一題填，產生房間碼；孩子在首頁輸入就能玩

關卡存在各人自己的瀏覽器裡，沒有後端伺服器。

## 在電腦上改程式

先安裝 [Node.js](https://nodejs.org/)（建議 LTS 版本）。

```powershell
npm install
npm run dev
```

瀏覽器開啟 http://localhost:5173/

改完並推到 GitHub 的 `main` 後，線上網站會自動更新。

## 老師怎麼出題

1. 打開網站後點「去蓋關卡」
2. 選年級、選遊戲，帶入範例或自己填
3. 按「產生房間碼」
4. 把四碼給孩子，在首頁輸入就能玩
